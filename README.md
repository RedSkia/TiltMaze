# TiltMaze

Labyrintspil: styr en kugle ved at vippe telefonen (Android) eller med piletaster/WASD (Windows). Træk broer på plads med fingeren eller musen. Baner hentes fra serveren og virker offline. Highscores gemmes lokalt og online.

Skoleprojekt i App-programmering 2026 (.NET MAUI Blazor Hybrid + ASP.NET Core API).

- Plan og kravspec: `docs/plan.md`, wireframes: `docs/wireframes.html`, PDF: `docs/TiltMaze-kravspec.pdf`
